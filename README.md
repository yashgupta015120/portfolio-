# Saubhagya Gupta Portfolio

A modern dark-themed personal portfolio website built with HTML, CSS, and vanilla JavaScript. It showcases technical skills, project highlights, hackathon achievements, and contact information in a polished developer-style layout.

## Preview

Open `index.html` in a browser, or run a local server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000/
```

## Features

- Responsive portfolio landing page
- Animated dark UI with glassmorphism and neon accents
- Typewriter effect for developer-style intro
- Skill matrix and project sections
- Hackathon spotlight section
- Interactive terminal-inspired UI
- Contact form with email integration via `mailto`
- GitHub profile link and profile image support

## Project Structure

```text
port 2/

```

## Files

- `index.html` — page structure and content
- `style.css` — styling, layout, and animations
- `script.js` — dynamic effects, counters, terminal simulation, and form behavior
- `image.png` — profile image

## Customization

You can easily personalize the portfolio by editing:

- Name and title in `index.html`
- Skills and project details in the main content sections
- Colors and layout in `style.css`
- Contact email in `script.js`
