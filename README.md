## 🚀 Overview

> *"Code. Build. Innovate. Translating logical structures into functional software."*

Welcome to the official repository for my personal software engineering portfolio. Engineered from scratch without heavy frontend frameworks, this web application features a **Modern Cyber/Studio** dark aesthetic that highlights my work across:

* 🐍 **Python Engineering:** Scripting, data modeling, backend logic, and automated workflows.

## ✨ Key Features

* **🎨 Cyber/Studio Glassmorphic UI:** Deep slate surfaces (`#0d0e12`), glowing cyan/emerald accents, a sticky `backdrop-filter` navigation header, and a live availability pulse indicator.
* **💻 Interactive VS Code Terminal (`v2.4.0`):** Built-in browser CLI (`saubhagya@vscode:~$`) with custom command parsing and one-click quick-action chips.
* **🏆 Flagship Hackathon Spotlight & Modal:** Dedicated showcase and interactive architectural deep-dive modal for **Dayflow HRMS** (built for the **Odoo x NMIT Hackathon**).

* **📬 Instant Clipboard & Toast System:** One-click email copy button with custom toast popup feedback and an integrated contact form.

## 🏆 Flagship Project: Dayflow HRMS

Developed for the **Odoo x NMIT Hackathon**, **Dayflow HRMS** is a modern Human Resource Management System prototype engineered to eliminate administrative friction across **4 core modules** and **7+ HR workflows**:

| Module | Architectural Responsibility |
| :--- | :--- |
| **1. Employee Directory** | Dynamic storage of departmental metadata, roles, contact coordinates, and reporting hierarchies. |
| **2. Automated Leave Engine** | Configurable approval trees that validate balance quotas, handle multi-tier approvals, and log audit trails. |
| **3. Attendance Sync** | Centralized time-in / time-out tracking with shift exception indicators and reporting dashboards. |
| **4. Security & Permissions** | Role-based access control separating standard employee views from administrative personnel capabilities. |

## 💻 Interactive VS Code Terminal

The portfolio includes an embedded **VS Code Live Terminal** simulator featuring workspace tabs (`main.py`, `algorithm.cpp`, `dayflow_hrms/`) and real-time command execution:

| Command | Quick-Run Button | Description |
| :--- | :--- | :--- |
| `help` | — | Lists all available terminal commands in the environment. |
| `about` | `about` | Displays developer bio, focus areas, and current status. |
| `python` | `run python` | Simulates running `main.py` automation and backend scripts. |
| `cpp` | `compile cpp` | Simulates compiling and executing `algorithm.cpp` DSA routines. |
| `dayflow` | `status dayflow` | Outputs system status and metrics for the Dayflow HRMS prototype. |
| `clear` | `clear` | Clears the terminal output buffer. |

## ⚡ Getting Started

Because this project is built with pure **HTML5, CSS3, and Vanilla JavaScript**, zero build tools or package installations are required.

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/yashgupta015120/your-repo-name.git](https://github.com/yashgupta015120/your-repo-name.git)
   ```
2. **Navigate into the project directory:**
   ```bash
   cd your-repo-name
   ```
3. **Launch locally:**
   * Open `index.html` directly in any modern browser, **or**
   * Start a local development server in **VS Code** using the **Live Server** extension, **or** run via Python:
     ```bash
     python -m http.server 8000
     ```
   * Visit `http://localhost:8000` in your browser.
